# Security Policy

## Supported versions

MyCore is under active development. Security fixes are applied to the latest revision of
`main`; older revisions and development branches are not maintained separately.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository and include enough
detail to reproduce and assess the issue. Do not disclose a suspected vulnerability in a public
issue or discussion.

If private vulnerability reporting is unavailable, contact the repository owner through their
GitHub profile without including sensitive details in the initial message.
